# 账号拆解结构框架（六问式）

> 蒸馏自一组系列化「小生意拆解」笔记的结构规律：每篇拆一个卖家账号/小店，固定六问推进，每问以一句加粗公式收尾。
> 本文只保留**结构与判断逻辑**，不含任何真实账号名、ID、经营数字或原文摘录。
> 适用：拆「卖货账号」（原版）与拆「任意内容账号」（扩展映射见文末）。

## 第0页｜案例概览（封面页）

固定信息位，按此顺序识图登记：

- 栏目头：系列名 + 期号
- 被拆账号截图字段：昵称、评分、已售、粉丝数、更新频率、售后标签条（退货包运费/好评率/平均发货/客服响应）
- 数据条：品类 ｜ 客单价；橱窗销量（通常做成红色大字，是视觉焦点）
- 两行黑体钩子句：**反常识结论**或**人群切口**——要么颠覆"这生意不赚钱"的常识，要么把宽品类收窄到一类具体的人
- 一行灰色点睛句：把整篇方法论压成一句话

信息优先级规律：**销量数字 > 人群切口 > 方法论金句**。

## 第1问｜这门生意赚的是谁的钱？（需求侧）

不要答"需要某品类的人"，要答出一类**审美或场景明确**的人。逐项确认：

- 目标人群画像：他们的共同特征是什么（审美取向/身份/生活方式），而不是他们缺什么
- 真实购买动机：是功能缺口，还是为了搭配、变好看、换风格、换个心情
- 触发场景：什么画面/时刻会让人想买（看到某套穿搭、某个出游或约会场景、被某张图种草）
- 决策关注点：下单前真正在意的几件事（好不好看、适不适合自己、好不好搭、价格有没有压力）

页底公式骨架：**这门生意赚的是「{人群定语}」的钱——他们买的不是{品类}的功能，而是{情绪或场景}**

## 第2问｜具体靠什么赚钱？（产品/价格/促销结构）

看货盘怎么被设计成一个"越买越多"的结构：

- 价格带：是否高度集中在某个低价区间、上限是否刻意压住 → 制造"顺手买"心理
- 拉新爆款：哪个单品负责把人吸进店（通常是价格最低、视觉最强的那个）
- 组合装：怎么把"买一件"变成"买多件"（任选N款、随机N个、套装）
- 满减门槛：门槛是否卡在略高于单件价格的位置 → 逼用户凑单
- SKU 宽度：是否大量同风格同价位商品 → 看中一个就能继续往下挑

页底公式骨架：**低价负责拉人，多款负责留人，满减负责让人多买**

## 第3问｜怎么让人看见并且想买？（内容/流量侧）

拆内容形式与它对应的心理作用：

- 平铺实拍图：颜色款式一次铺开 → "好多、都好看"的视觉冲击
- 上身图/使用场景图：把商品带进真实场景 → "我用是什么效果、我能怎么搭"
- 标题公式：是否直接把价格和产品一起抛出 → 颜值刺激与价格刺激同时到达
- 可信度补强：是否用制作细节叙事（改版次数、选材过程）给低价商品加"认真做产品"的信任
- 内容链路：把上面几项串成一条因果链（高颜值留人 → 场景唤起需求 → 低价推冲动）

页底公式骨架：**高颜值负责让人停下来，场景图负责让人想要，低价负责让人觉得"买了也不亏"**

## 第4问｜看完之后怎么让人下单？（转化/信任侧）

- 链路长度：从种草到付款是否全程站内、有没有跳出
- 商品页的二次推动：店铺券、满减券、加购自动改价，怎么把一件凑成两三件
- 信任资产：逐项登记评分、好评率、发货时效、无理由退货、极速退款、晚发必赔等标签——这些是用来压"这么便宜会不会踩坑"的最后顾虑的
- 阻力消除：确认从"这个挺好看"到付款之间，还剩哪些犹豫点、分别被什么机制消掉

页底公式骨架：**价格让人敢买，优惠让人多买，售后让人放心买**

## 第5问｜普通人能不能学？最值得学习的是什么？（决策侧，通常拆 2 页）

1. **为什么能跑通**（约 4 条）：决策成本是否趋近于零／视觉刺激与满减机制的组合拳是否真的拉高了客单／店铺兜底能力是否足以打消低价疑虑／内容生产能力（原创条数、更新持续性，用数量对抗算法不确定性）
2. **普通人能不能学**——务必分两档回答，不要给单一结论：
   - 轻资产副业档：找同款、买样品、自己拍图文挂车赚零花钱，门槛与风险各是什么，跑得通吗
   - 重资产规模档：要做到截图里那个销量量级，需要什么样的供应链、人力（打包/代发仓/专职客服）、单件毛利结构；为什么这是"拼量拼效率拼成本"的苦生意，普通人扛不住在哪
3. **最值得学习的是什么**（提炼成"三板斧"）：价格锚点是否极清晰／凑单机制是否真的在拉客单／是否用实拍图代替网图（制造独家感与丰富感，降低比价欲望）
4. **最大的风险是什么**（约 4 条）：退货率吞噬利润（实物与图片的色差质感差 → 退货率与单件退回运费的量化关系）／履约成本（包邮快递费 + 包装 + 平台扣点，不凑单是否单件就亏）／同质化与价格战（是否公模无壁垒）／库存风险（审美迭代速度 → 死库存）

## 正文收尾（笔记 desc 的固定结构）

- 一句话生意本质（这门生意到底赚的是什么钱）
- 普通人能学的几点 / 学不了的几点
- 最大的坑（一句警告）
- 互动问句（下期想拆什么 / 留言区答疑）
- 免责声明（仅拆解分享，不招募不推荐）
- 话题标签组

## 扩展映射：拆「任意内容账号」时的字段替换

| 原版（卖货账号） | 任意账号替换为 |
|---|---|
| 品类/客单价/橱窗销量 | 内容赛道/更新频率/赞藏粉与爆款率 |
| 赚谁的钱（买家） | 赚谁的注意力与信任（读者画像+需求） |
| 靠什么赚钱（货盘） | 变现组合（橱窗/商单/知识付费/私域/直播/店铺） |
| 怎么被看见（内容） | 内容结构（栏目化/封面SOP/标题公式/更新节奏/视觉资产） |
| 怎么让人下单（转化） | 转化路径（主页→合集→橱窗/私域/直播间的钩子链） |
| 能不能学/风险 | 同构：为什么跑通/学习门槛/可抄三板斧/风险（平台依赖/人设塌/同质化/断更） |

## 报告硬约束

- 每板块一句「一句话公式」收尾（加粗）。
- 数字必须带来源页标注（封面/第N页/主页列表）；未获取写「未获取」，禁编造。
- 主页列表数字与笔记详情冲突时，以笔记详情为准，并在报告中标注差异。
- 不冒充被拆账号口吻，全程拆解者第三人称视角。
- 结尾固定三段：能抄的 / 抄不了的 / 最大的坑。
